# Cybersecurity-Lab-with-Docker-macOS

🐳 Beginner Cybersecurity Lab with Docker + Docker Scout (macOS)
In this mini project, I followed Ben Truong’s "Build a Beginner Cybersecurity Lab at Home" guide to set up a simple, container-based security lab using Docker on macOS. I created and ran a Linux container, then used Docker Scout to scan the image for vulnerabilities.

🛠️ What I Did
- Installed Docker Desktop on my Mac.
- Pulled a basic Debian image from Docker Hub.
- Created and ran a Linux container from the image.
- Used Docker Scout to scan the container image for CVEs (Common Vulnerabilities and Exposures).
✅ Scan Results: 0 vulnerabilities found.
